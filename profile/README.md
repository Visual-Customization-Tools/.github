# Visual Customization Tools (VCT) 🎨

Welcome to the official GitHub organization for **VCT**. We are a team of developers and designers creating lightweight, intuitive tools for real-time visual asset swapping, inventory previewing, and customization in modern multiplayer games.

Our mission is to provide players with a seamless way to personalize their in-game appearance and manage their collections effortlessly.

---

### 🚀 Our Ecosystem

Explore our open-source projects designed to work together:

* 🎯 **[Valorant Skin Swapper 2026](https://github.com/Visual-Customization-Tools/valorant-skin-swapper-2026)**: A lightweight tool for real-time visual swapping of weapon textures, animations, and sound effects on your local display. Preview and personalize your inventory appearance effortlessly.
* ⚙️ **[VCT Core Libs](https://github.com/Visual-Customization-Tools/vct-core-libs)**: Core backend C++ libraries for asset management, memory hooking, and real-time rendering integration. Powers our main application.
* 🌐 **[VCT Web Dashboard](https://github.com/Visual-Customization-Tools/vct-web-panel)**: A React-based web interface for managing configurations, toggling visual assets, and syncing your local inventory database.
* 📖 **[VCT Documentation](https://github.com/Visual-Customization-Tools/vct-docs)**: Technical documentation, API references, and reverse engineering notes for developers integrating our tools.
